# WN

Offline Android noise mixer and audio-profile tools.

The app generates continuous noise from a fixed default curve and saved frequency-band profiles. Each generator has its own level, with shared master volume and stereo width. Profiles use a portable JSON format and can be imported, exported, or created from microphone recordings and audio files. A Python/FFmpeg profiler provides the same format on desktop.

This repository contains the Android app, desktop tooling, tests, and APK build workflow.
